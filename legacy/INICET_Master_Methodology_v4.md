# INI-CET Master Tracker v4 — methodology

Built: 27 September 2026.

## What is merged
- Original evidence catalogue: 120 curated recall records, 57 targets, 19 integrated blocks.
- Deep map: 388 microtopics nested under the 57 core targets.
- Restored overlays: 11 microtopics from the earlier prototype (pharyngeal apparatus and image grammar).
- Supplemental web layer: 78 task-level recall records, kept separate from the curated denominator.
- 19-subject web topic census for breadth, explicitly not frequency counts.

## Non-negotiable evidence rules
1. Recall sources are not official authenticated question papers.
2. Curated recurrence counts use only the original audited ledger. Supplemental tasks do not inflate them.
3. Study scores are editorial priority, not predicted probability.
4. Practice/predicted patterns are labelled inference.
5. Current subject-wise percentage weightage is not claimed as known.
6. Legal/treatment/screening items require current verification.
7. Disputed answer keys are stored as task-only with a warning.

## Cross-platform
The standalone HTML works without a server on desktop browsers. The PWA package is for HTTPS static hosting and home-screen installation on iPad/iPhone and installable desktop browsers.
