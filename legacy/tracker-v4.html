Evidence model

Core ledger: 120 curated recall records across the project research window. Supplemental web tasks are displayed separately and are not silently added to the curated recurrence denominator.
Official exam scheme source in this package: 200 questions, 180 minutes, +1/−⅓/0, split into four sequential 50-question/45-minute parts in the July 2025 prospectus. Always check the current-session prospectus.
Current subject percentages are not treated as reliably estimable. External 2026 weightage pages explicitly describe online numbers as estimates because AIIMS does not publish a fixed subject distribution.

How predictions are handled

Green items = recall-linked/supporting evidence. Amber items = practice/predicted transformations. They are designed to mimic question-form changes, not to claim a future paper prediction or probability.

Windows / macOS

Open INICET_Master_Tracker_v4.html directly in Chrome, Edge, Safari or Firefox. Checkmarks and notes are stored locally in that browser. Use Export/Import backups.

iPadOS / iOS

Best experience: use the PWA folder on an HTTPS static host, open in Safari → Share → Add to Home Screen. For local-only use, open the standalone HTML in an app that previews HTML + JavaScript. iOS Quick Look may show only a static/text preview.

PWA

The ZIP contains index.html, manifest, service worker, icons, the merged JSON dataset, the original catalogue and methodology. Host as static HTTPS files; no backend is required.

Corrections retained

The project correction notes remain important: DPP-4 renal dosing should not be learned as a blanket contraindication; tirzepatide is dual GIP/GLP-1; duplicated recall entries are not double-counted; disputed May 2026 keys are flagged task-only rather than endorsed.
